# ExpoFlow Landing Page

A static concept landing page for the proposed exhibition and event management platform.

## Files
- `index.html` — page structure and copy
- `styles.css` — responsive styling and dashboard mockup
- `script.js` — demo form interaction and current year

## Run locally
Open `index.html` directly in a browser, or serve the folder with any simple local web server.

## Notes
- The product name **ExpoFlow** is a working name and can be replaced.
- The dashboard shown in the hero is a visual mockup; it is not connected to a backend yet.
- The demo form currently provides front-end confirmation only.
